# Arbor Vista Platform v4.3 — Premium UI Test Build

This package is a complete upgrade of the v4.2.1 platform with a calmer, more editorial public website.

## Test locally

The current GitHub Pages build uses `/ArborVista-Labs/` as its base path. Serve the folder that contains an `ArborVista-Labs` directory, then open:

```text
http://localhost:8080/ArborVista-Labs/
```

For GitHub Pages, upload all package contents to the root of `swasamventure/ArborVista-Labs`.

## Main visual changes

- Supplied Arbor Vista logo lockup
- Playfair Display and DM Sans typography
- One-image hero
- Seven total homepage photographs, including the hero
- Curated Cabin page
- Full image collection remains on `gallery.html`
- Five-item public navigation
- Static-host-compatible output

The operational backend and dashboard remain unchanged from v4.2.1. Database v1.0 is included under `data-layer/database` for future containerized deployment.
