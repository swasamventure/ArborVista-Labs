# Uploading v4.3.2 to ArborVista-Labs

1. Extract the complete package.
2. Upload the contents inside the extracted project directory to the repository root.
3. Confirm `index.html`, `assets/`, `images/`, `admin/`, `Backend/`, and `data-layer/` remain at the root.
4. Commit the files to `ArborVista-Labs`.
5. Wait for GitHub Pages to publish.
6. Test the homepage, Cabin, Gallery, Explore, and Book Direct pages on desktop and mobile.

Do not promote to `ArborVista-Retreat` until the test release is approved.
