# Upload v4.3.1 to GitHub

1. Extract the complete ZIP.
2. Upload the files inside the extracted project folder to the root of `ArborVista-Labs`.
3. Replace matching older files.
4. Commit the changes.
5. Test `index.html`, `cabin.html`, and `book-direct.html` through GitHub Pages.
6. After approval, promote the same tested files to `ArborVista-Retreat`.

Do not upload the ZIP itself into the repository.
