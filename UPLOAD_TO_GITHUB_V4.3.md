# Upload Arbor Vista Platform v4.3 to GitHub

1. Extract `ArborVista_Platform_v4.3_Premium_UI_QA_GitHub_Ready.zip`.
2. Upload all extracted files and folders to the root of `swasamventure/ArborVista-Labs`.
3. Replace older files when prompted.
4. Confirm `index.html`, `assets/`, `images/`, `admin/`, `Backend/`, and `data-layer/` are at repository root.
5. Wait for GitHub Pages deployment.
6. Test the home, Cabin, Gallery, Book Direct, and Market Intelligence pages.

The public UI is static. Backend-dependent dashboard functions still require the local server or future cloud deployment.
